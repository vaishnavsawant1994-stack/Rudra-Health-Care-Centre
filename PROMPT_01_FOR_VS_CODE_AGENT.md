## Design direction
Professional, modern, trustworthy healthcare service brand; calm white/light surfaces, strong legible text, restrained teal or blue accents that can be changed through tokens; uncluttered calls to action; responsive desktop/tablet/mobile. The site should make **Rudra Health Care Centre** primary and identify Metropolis appropriately as a diagnostic franchise partner with wording pending contractual approval.

## Safety
Use synthetic/no patient data, no artificial lab reports, no fabricated prices, no real payment claims, no demo login that appears to authenticate, and no nonfunctional 'Book Now' success message. Avoid showing medical advice as if verified.

## Acceptance
The default dev command starts the project, the six routes render, navigation works, mobile layout is sound, lint and build pass, and the output truthfully distinguishes wired functionality from shells.

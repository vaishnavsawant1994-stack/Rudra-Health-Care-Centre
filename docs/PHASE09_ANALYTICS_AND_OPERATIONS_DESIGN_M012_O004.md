# Rudra Phase 09 analytics and operations previews M012–O004

This increment adds eleven screenshot-guided dashboards: M012 analytics, M013 lead attribution, M014 website SEO, M015 marketing automation, M016 reports and exports, M017 conversion funnel, M018 access/budget/audit governance, O001 owner command centre, O002 branch operations, O003 centre directory and setup, and O004 service area / capacity.

All people, centre activity, counts, source records, budgets, rates, attribution and operations in these previews are synthetic illustrative examples. Charts are code-rendered; no production analytics or patient data is fetched. Preview controls do not export, publish, update permissions, approve budgets, change centres, schedule collections or otherwise write operational records.

Protected marketing references use `/marketing/design/m012` through `/marketing/design/m018`; protected owner references use `/owner/design/o001` through `/owner/design/o004`. Local development-only routes use `/design-preview/marketing/m012` through `/m018` and `/design-preview/operations/o001` through `/o004`. The shared design-preview layout blocks these local routes in production.

Pixel-level acceptance requires browser comparison with the source screenshots at the intended viewport dimensions.
